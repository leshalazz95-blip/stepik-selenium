# stepik-selenium

Домашние задания по курсу «Автоматизация тестирования с помощью Selenium и Python».

## Задачи из модуля

Файлы лежат в папке `new_course_selenium/`:

- `alert.py` — работа с alert (switch_to.alert)
- `execute_script.py` — прокрутка страницы через execute_script
- `required_text.py` — явные ожидания (text_to_be_present_in_element)
- `switch_to_window.py` — переключение между вкладками
- `file_upload.py` — загрузка файла через send_keys
- `checkboxes.py`, `radiobuttons.py` — работа с чекбоксами и радиокнопками
- `work_by_selectors.py` — поиск элементов по CSS-селекторам
